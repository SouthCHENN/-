# Handoff: 走着 · 单文件离线旅行行程 App

## Overview
「走着」是一款单文件离线旅行行程应用：一次旅行 = 一份数据包。核心场景是旅途中断网时知道"此刻该干嘛、下一步去哪"。无账号、无后端、无实时数据。本包包含已定稿的交互原型（可点击 HTML）与全部规格，目标是打包为 Android APK（首要兼容小米 15 Pro）。

内置真实数据：意大利 13 天行程（2026.9.24–10.6，罗马→索伦托/卡普里→佛罗伦萨→威尼斯→米兰），含 110+ 时间线节点、住宿/餐厅/行李寄存、票务与订位待办、应急电话。

## About the Design Files
本包中的文件是 **HTML 设计参考**（原型，展示预期外观与行为），不是可直接上架的生产代码。任务是在目标环境中**重建**这些设计：
- 推荐路径 A（最快）：WebView / TWA 壳工程直接承载 `走着-离线单文件.html`（该文件已自包含：字体、运行时、数据全内置，断网可用），十分钟出 APK。
- 路径 B（原生）：按本 README 用 Compose/Flutter/React Native 重建。数据模型与交互规格见下文。

`走着.dc.html` 是源文件（模板 + 逻辑类 + 数据包），`support.js` 为其运行时，二者是阅读逻辑的依据；`走着-离线单文件.html` 是编译产物，勿手改。

## Fidelity
**High-fidelity**。颜色、字号、间距、动效时长均为最终值，按像素级重建。

- 背景：`#05070D`（页外）/ `#0A0F1C`（App 底）/ `#0D1424`（bottom sheet）/ 卡片 `rgba(255,255,255,.03)`
- 品牌青（交互色）：`#00F0FF`——选中态、主按钮、tab 激活、勾选、链接；浅底用 `rgba(0,240,255,.04–.16)`，描边 `.2–.5`
- 品红（状态色）：`#FF2E88`——NOW 标记、行李日、应急卡、当前站点；浅底 `rgba(255,46,136,.07–.12)`
- 文字：主 `#D8E6F0` / 次 `#9FB6C9` / 弱 `#5E7186` / 禁用 `#3A4A5C` / 强调白 `#fff`
- 在线指示绿：`#2EE86C`
- 字体：中文/正文 `Noto Sans SC`（400/500/700/900）；等宽标签/时刻 `Share Tech Mono`
- 字号：标题 17–24px、正文 13–14px、次要 11–12px、mono 标签 9–11px
- 圆角：2–4px（赛博朋克直角感）；发光：`box-shadow: 0 0 10–18px rgba(青/品红,.25–.6)`

## Screens / Views

### 1. 顶栏（常驻）
走着 wordmark（19px/900/青色发光）+ 「意大利 · 9.24–10.6」+ 状态徽章（T-N 出发 = 青 / DN 进行中 = 品红 / 已结束 = 灰）+ 网络指示点（绿=在线，品红=离线，实时监听 online/offline 事件）。

### 2. 行程（默认落点 tab）
- **日期滑轨**（sticky 顶部，仅此页有）：D1–D13 芯片（52×48px，mono），选中青色发光；行李日芯片带品红 BAG 角标；点击/横滑切天；切天后该芯片滚动停靠滑轨最左。
- **预出发横幅**（仅旅行未开始）：「旅行未开始 · 正在看 D{n} 计划 | T-N DAYS」。
- **每日头图**（172px）：城市渐变底 + SVG 霓虹剪影插画（图内无文字）——罗马=穹顶+斗兽场、索伦托=维苏威海湾、卡普里=三巨岩、佛罗伦萨=圣母百花、威尼斯=钟楼+贡多拉、米兰=大教堂尖塔群；日/月圆 + 地平网格线；文字叠层：D{n} · 日期 / 周几 · 城市 / 当日摘要。SVG 路径数据在源文件 `artFor()`。
- **行李日提示条**（仅 D5/D8/D10/D11/D13）：品红底条 + 「行李日」徽章 + 动线一句话。
- **路线示意图**（可交互）：水平站点连线图，站点 = 当日关键节点（映射见 `rtOf()`），段上标交通方式；站点三态（已过灰 / 当前品红发光 / 未来青描边）+ 站名 + 时刻；**点击站点弹对应节点卡片**；下方显示当日 ⚠ 提示（如雨备方案）。
- **时间线**：每节点 = 时刻(mono) + 圆点轨 + 标题 + 副说明 + 可选标签(🎫/🧳/🚄/⛴)。三态：已过 40% 置灰 / 当前品红点脉冲动画 + NOW 徽章 + 左侧 2px 品红轨 + 行底 `rgba(255,46,136,.07)` / 未来常规。含「备选方案」的节点内联折叠（▸/▾ 点击展开，不触发卡片弹出，stopPropagation）。
- **住宿 & 饭店**（可折叠卡）：今晚住宿（名称/地址/电话 + 复制键，电话可 `tel:` 拨打）、今晚饭店（名称/订位信息 + 复制）、行李日追加寄存状态块（寄存中/待取 + 时间窗）。D13 无住宿显示「今晚在航班上」。

### 3. 总览 tab
- **头图**（172px，可点）：旅行前/后 = 旅行头图（罗马剪影 + 全程标题「罗马→索伦托→佛罗伦萨→威尼斯→米兰」），点击跳 D1；旅行中 = 当天头图，点击跳当天行程。
- **13 天列表**：D 序号（当天品红）/ 日期+周几 / 摘要 / 行李日角标；整行热区，点击跳行程页并定位该天。

### 4. 待办 tab（三段控件：今日待办 / 行程待办 / 应急信息）
- **今日待办**：D1–D13 日期芯片（默认今天；旅行前默认空态 + 提示，可点任意天预览）；清单 = 当日专属项 + 每日通用项（带「每日」角标）；勾选态：青色填充✓ + 置灰划线，可撤销；计数行「D5 · 9.28 索伦托 · 已完成 2/9」。
- **行程待办**：三组——旅行前·票务与确认（9 项，其中"坎帕尼亚快线补票"已作废默认勾选）/ 旅行前·餐厅订位（11 项按紧急度）/ 旅行中·每日通用（只读模板，注明"已按天生成进今日待办"）；底部注明无需订位餐厅清单。
- **应急信息**：‹ › 切日期（跨国行程时随日期切当地信息；本次全程意大利各日一致）；意大利全国通用卡（112/113/118/115，号码 `tel:` 可拨 + 复制）；领事保护卡（驻意使馆 +39 06 9652 4200、外交部 12308）；当日应急落点卡（当晚住宿名称+地址+电话+复制）。

### 5. 节点卡片（bottom sheet）
上下文行（D5 · 9.28 · 10:45，品红 mono）→ 节点名（17px/900）→ 完整地址 → 凭证块（青色浅底：订单号/取票说明）→ 电话行（可拨 + 复制）→ 双按钮：**复制地址**（青色实底主按钮）+ **唤起在线地图**（品红描边；离线时置灰 + toast「离线中·无法唤起在线地图」；在线时打开 Google Maps query URL）→ 离线边界说明一行：「离线可用：地址/凭证/电话 · 需联网：在线地图导航」。

## Interactions & Behavior
- 日期轴点击/**内容区横滑**（dx>70 且 |dx|>2|dy|）切天：内容水平滑动转场 280ms ease；方向随切换方向。
- 时间线节点/路线图站点点击 → bottom sheet 上滑入场 260ms `cubic-bezier(.32,.9,.35,1)`，蒙层 `rgba(2,4,10,.55)`；点蒙层/下滑手柄（dy>60）/切 tab 关闭。
- tab 切换无转场直切；激活 tab 顶部 2px 青色霓虹条 + 图标发光。
- 所有复制操作：`navigator.clipboard` + toast（青色玻璃态，1.7s 自动消失，底部 88px 居中）。
- NOW 脉冲：`box-shadow` 品红 1.6s ease-in-out infinite。
- "现在"判定：真实时钟，每 60s 刷新；当前节点 = 当天时间线中最后一个 `时刻 ≤ now` 的节点，保持 NOW 直到下一节点时刻；跨天：早于今天全 past，晚于全 future。原型提供 `simNow` 调试参数（如 `9.28 11:30`）模拟时间，生产可保留为开发者选项。
- 旅行前：状态徽章 T-N，行程页横幅倒计时，今日待办空态；旅行后：徽章"已结束"，总览回旅行头图。
- 头图加载失败降级（若替换为位图）：纯色块 + 日期标题。

## State Management
- `view`(overview/today/todo) / `day`(1–13) / `todoSec`(daily/trip/emg) / `todoDay`(0=未选,1–13) / `sheetOpen`+`sheet`(节点引用) / `altIdx`(展开的备选) / `stayOpen` / `online` / `toast`
- 勾选状态三组 map：`doneDaily`(键 `{day}-s{i}` / `{day}-g{i}`)、`donePre`、`doneBook`
- **持久化**：localStorage 键 `zouzhe_italy_2026_v1`，存勾选 + view/day/todoSec/todoDay，启动恢复；生产建议换 SharedPreferences/DataStore。
- 启动落点：旅行中 = 今天；否则 D1。

## Data Model（数据包 = 一次旅行）
源文件 `trip()` 返回 13 个 day 对象：
```
day: { n, date:'9.28', wk:'一', city:'索伦托', sum, route, tip?, bag?, bagLine?,
  stay:{name,addr,tel}|null, dinner:{name,info,tel?}|null,
  deposit:{tag,line,sub}?, daily:[string],
  nodes:[{ t:'10:45', sm:分钟数, title, sub, tag?, addr?, note?, tel?, alt? }] }
```
另有 `preRaw()` 票务待办、`bookRaw()` 订位待办、`genRaw()` 每日通用、`emgRaw()`/`consRaw()` 应急电话、`rtOf(n)` 路线图站点（label + 节点索引）、`artFor(city)` 头图 SVG 路径、`gradOf(city)` 渐变。换一次旅行 = 换这份数据包。

## Assets
无外部图片。全部图形为内联 SVG（头图剪影、缩略图）与 CSS 渐变。字体经 Google Fonts 引入，离线单文件已内嵌；原生实现请打包 Noto Sans SC + Share Tech Mono（或 JetBrains Mono 等宽替代）。

## APK 打包建议（路径 A 详细）
1. Android Studio 新建空项目，`assets/` 放入 `走着-离线单文件.html`。
2. 单 Activity + WebView：`loadUrl("file:///android_asset/走着-离线单文件.html")`；开启 `javaScriptEnabled`、`domStorageEnabled`（localStorage 持久化必需）。
3. 竖屏锁定；主题深色 `#0A0F1C`（含状态栏）；图标可用包内缩略图 SVG 重绘。
4. `shouldOverrideUrlLoading` 拦截 `tel:`（转 Dialer）与 `maps.google.com`（转外部浏览器/地图 App）。
5. 断网验证：飞行模式下全部数据可用，仅"唤起在线地图"置灰。
